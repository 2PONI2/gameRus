# Правила проекта для ИИ-ассистента

Игра: кооператив 2-4 игрока в духе Overcooked на тему взаимопомощи и созидательного труда, традиционные ценности России (семья, уважение к старшим, "всем миром"). Тон тёплый, добрый, с юмором. Без насилия, оружия, политической агитации.

## Технические рамки
- Unity 6 LTS, C#, URP, Input System, TextMeshPro.
- Netcode for GameObjects + Unity Transport + Relay + Lobby. Хост авторитетный. Локальная игра = Host без клиентов, один код на оба режима.
- Весь текст для игрока на русском, шрифт с кириллицей.
- Данные (предметы, рецепты, заказы, уровни) в ScriptableObject, новый уровень добавляется без правки кода.
- Всё, что обычно делается руками в редакторе, делается Editor-скриптом: меню Tools/Build Game.

## Правила кода
- Полный рабочий код без заглушек. Путь файла указывать полностью.
- namespace и asmdef по папкам Assets/Scripts/*.
- Без магических чисел, без аллокаций в Update.
- Не выдумывать API пакетов. Не уверен в сигнатуре: скажи об этом и сверься с документацией.
- Перед кодом краткий план, после кода инструкция запуска и чек-лист проверки.
