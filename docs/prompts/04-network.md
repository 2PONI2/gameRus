# Промт 4. Сеть (Netcode + Relay + Lobby)

```
Этап 4. Сделай сетевой режим для 2-4 игроков без собственного сервера.

Требования:
- Netcode for GameObjects + Unity Transport + Unity Relay + Lobby. Хост создаёт комнату, получает короткий код, друзья вводят код и подключаются. Инициализация Unity Gaming Services с анонимной аутентификацией.
- Экран лобби: список игроков, готовность, выбор персонажа, выбор уровня хостом, старт игры.
- Авторитетный хост: заказы, таймер, очки, станции, предметы считаются на хосте. Ввод клиента отправляется RPC, позиции игроков синхронизируются с интерполяцией. Объясни, как сделана передача предметов без дублирования и потери.
- Корректная обработка: отключение клиента посреди уровня, ошибка подключения, потеря хоста (вернуть всех в меню с сообщением).
- Запасной режим: LAN / прямой IP через Unity Transport без UGS (на случай, если Relay недоступен).
- Локальный режим остаётся и использует тот же код (Host без клиентов).
- Подробная инструкция: как создать проект в Unity Dashboard, включить Relay и Lobby, привязать проект в редакторе, какие пакеты поставить и в каких версиях. Если не уверен в актуальном API пакетов - прямо отметь это и дай способ проверить по документации.
- Инструкция по тесту сети на одном ПК (ParrelSync или Multiplayer Play Mode) и на двух компьютерах.

Отдельно предупреди об ограничениях бесплатного уровня Relay/Lobby, и как их проверить.
```
