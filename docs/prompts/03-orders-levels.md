# Промт 3. Заказы, очки, уровни, UI

```
Этап 3. Дополни проект:

- Система заказов (ScriptableObject-рецепты, очередь с таймерами, UI-карточки заказов как в Overcooked, звук/анимация появления и провала).
- Подсчёт очков, серии, чаевые, звёзды, экран итогов, пауза, рестарт.
- Менеджер уровней: LevelData (ScriptableObject) определяет сцену, заказы, длительность, пороги звёзд, число игроков. Масштабирование сложности от числа игроков.
- Реализуй уровни 1-4 по дизайн-документу, у каждого уникальная механика-препятствие. Уровни 5-6 "всё вместе" - реализуй каркас и один готовый.
- Механики обязательной взаимопомощи (совместный перенос, "один держит - другой работает").
- Главное меню: Играть локально / Играть по сети / Выбор уровня / Настройки (громкость, управление) / Выход. Сохранение прогресса (звёзды) в JSON.
- Короткие дружелюбные реплики NPC и подсказки, текст на русском.

Обнови Editor-скрипт, чтобы он собирал все эти сцены. В конце - чек-лист и ограничения.
```
