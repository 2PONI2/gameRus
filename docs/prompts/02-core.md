# Промт 2. Ядро: игрок и предметы, локальная игра

```
Этап 2. Реализуй по одобренному документу вертикальный срез ядра, пока на ОДНОМ уровне и только локально (но архитектура уже под Netcode: игрок и предметы - NetworkObject, ввод передаётся на хост).

Сделай:
- Editor-скрипт Tools/Build Game: создаёт Input Actions, слои, префабы (игрок, ресурсы, станции), сцену Level_Test, добавляет сцены в Build Settings.
- Управление игроком: ходьба, подобрать/положить, "работа" по удержанию, бросок, рывок. Плавная физика в стиле Overcooked (ускорение, трение, без застревания).
- Локальная мультиигра: до 4 игроков, клавиатура (2 схемы: WASD+E/Q и стрелки+Enter/RShift) + геймпады, подключение по нажатию кнопки "Присоединиться" на экране выбора.
- Система предметов (ScriptableObject): ресурс, "промежуточный предмет", готовое изделие.
- Станции с прогресс-баром, визуальный индикатор что в руках у игрока (иконка/модель над головой).
- Заглушки арта - цветные примитивы, но с чёткой читаемостью (форма+цвет+иконка).

Критерии готовности: 2-4 локальных игрока могут пройти цепочку "взять ресурс - обработать - собрать - сдать". В конце - чек-лист ручного тестирования и список известных ограничений.
```
