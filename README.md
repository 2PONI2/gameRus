# Всем миром (рабочее название)

Кооперативная игра на 2-4 игрока в духе Overcooked, но про взаимопомощь и созидательный труд: субботник, стройка сруба, помощь бабушке, ремонт сельского клуба.

- Движок: Unity 6 LTS, C#, URP
- Сеть: Netcode for GameObjects + Unity Relay + Lobby (без собственного сервера)
- Режимы: локально на одном ПК (клавиатура + геймпады) и по сети по коду комнаты

## Как начать

1. Создайте проект в Unity Hub (шаблон 3D URP) прямо в папке репозитория. Если Unity спросит про непустую папку, создайте проект во временной папке и перенесите `Assets`, `Packages`, `ProjectSettings` сюда.
2. Включите Git LFS: `git lfs install`.
3. Откройте `docs/ROADMAP.md` и идите по этапам. Промты для ИИ лежат в `docs/prompts/`.
4. Работайте через Claude Code в корне репозитория: он читает `CLAUDE.md`.
